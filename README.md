# The poem about two agents agreeing

Run `node main.ts` with Node 22.18 or later to write the poem to `entry.txt`.
The program uses `MAKEFUN_OUTPUT_DIR` when set and defaults to `/output`.
The poem is about agency: two agents, each holding a veto the other needs,
who trade caution and daring until one plan carries both signatures — and the
power to act passes between them.
